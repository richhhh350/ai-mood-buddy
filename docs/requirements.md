# AI 心情搭子：需求说明 v1.0

## 1. 产品背景

人在烦躁、疲惫或思绪混乱时，常常只能说出“有点烦”“不知道怎么回事”等模糊感受，也很难立刻决定下一步做什么。

AI 心情搭子帮助用户记录此刻的感受，将一段自然语言整理成清晰的情绪反馈，并给出一个容易执行的小行动。它是日常情绪整理工具，不是心理诊断或医疗服务。

## 2. 目标用户

第一版主要服务于希望快速梳理当下心情，但不想写长篇日记的普通用户。

典型使用场景：

- 工作或学习受挫后，用户想弄清自己为什么烦躁。
- 一天结束时，用户想简单记录当天的情绪。
- 用户知道自己状态不好，但不知道接下来可以做什么。

## 3. 核心价值

用户只需输入一段心情描述，就能得到：

1. 一个主要情绪名称和对应表情。
2. 一句简短、自然、不说教的回应。
3. 一个五分钟左右可以完成的行动建议。
4. 一条可在本机查看和删除的心情记录。

## 4. 核心使用流程

1. 用户打开网页，在输入框中描述此刻的心情。
2. 用户点击“分析一下”，页面显示正在分析的状态。
3. 系统返回情绪名称、情绪强度、共情回应和行动建议。
4. 系统自动将本次输入与分析结果保存到本机数据库。
5. 用户可以在“最近记录”中查看历史结果，并删除任意一条记录。

## 5. 第一版功能范围

### 5.1 心情输入

- 用户可以输入 1～500 个字符。
- 输入内容在提交前去除首尾空格。
- 输入为空或只有空格时，不发送分析请求，并显示明确提示。
- 分析期间禁用提交按钮，防止重复提交。

### 5.2 AI 心情分析

每次成功分析必须返回以下字段：

| 字段 | 说明 | 限制 |
|---|---|---|
| `mood` | 主要情绪名称 | 2～8 个中文字符 |
| `emoji` | 情绪对应表情 | 1 个 emoji |
| `intensity` | 情绪强度 | 1～5 的整数 |
| `response` | 共情回应 | 不诊断、不说教，不超过 80 个中文字符 |
| `action` | 行动建议 | 明确、具体，约 5 分钟内可以完成 |

### 5.3 心情卡片

分析成功后，页面展示一张结果卡片，包含：

- 用户的原始输入；
- 情绪名称和 emoji；
- 1～5 级情绪强度；
- 共情回应；
- 行动建议；
- 创建时间。

### 5.4 历史记录

- 每次成功分析后自动保存记录。
- 记录保存在用户电脑的本地数据库中，关闭或刷新网页后仍然存在。
- 页面按创建时间从新到旧展示最近 20 条记录。
- 用户可以删除任意一条记录。
- 删除成功后，该记录立即从页面消失，刷新后也不会再次出现。

### 5.5 异常反馈

- 输入为空时，在输入框附近显示“请先写下你现在的感受”。
- 输入超过 500 个字符时，显示“最多输入 500 个字符”。
- AI 请求失败或超时时，显示“暂时没有分析成功，请稍后重试”。
- 分析失败的内容不写入历史记录。

## 6. 第一版不做

- 不注册或登录账号。
- 不在多台设备之间同步记录。
- 不做社交分享、评论或排行榜。
- 不提供心理疾病诊断、药物建议或医疗结论。
- 不主动推送提醒。
- 不分析图片、语音或视频。
- 不根据长期历史记录建立用户画像。

## 7. 安全边界

- 页面明确说明本产品不能替代专业心理或医疗帮助。
- AI 不得声称用户患有某种心理疾病。
- 当输入明显涉及自伤或伤害他人的风险时，不生成普通行动建议；页面应优先提示用户联系当地紧急服务、专业机构或可信任的人。
- API 密钥只保存在后端环境变量中，不发送到浏览器，也不提交到 Git 仓库。

- [x] 抽查行动建议描述一个明确动作，并以约五分钟内可以完成为目标。
- [x] 空输入和全空格输入不会发送请求，页面显示“请先写下你现在的感受”。

- [x] 分析成功后，记录出现在历史列表顶部。

## 9. 项目成功指标

第一版用于学习和演示，不追求真实用户增长。成功指标为：

- 完整走通一次“输入—分析—保存—查看—删除”流程。
- 所有自动化测试通过。
- API 密钥未出现在前端代码或 Git 提交中。
- 项目能够在全新虚拟环境中按照 README 成功启动；其他操作系统另行验证。

## 10. 一句话介绍

AI 心情搭子是一款面向想快速梳理当下感受的用户，通过简短输入提供情绪反馈、微行动建议和本地心情记录的网页应用。

## 11. 后续版本候选项

以下内容仅作为未来设想，不属于第一版承诺：

- 用户自定义情绪标签。
- 将心情卡片导出为图片。
- 语音输入。
- 可选择不同风格的回应方式。
